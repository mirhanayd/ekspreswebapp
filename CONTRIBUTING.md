# Contributing to Siirt Kurtalan Ekspres Demo MVP

Thank you for contributing! This is a private, owner-only project repository for the Demo MVP.

## Getting Started
1. Ensure you have Node.js, pnpm, and Docker installed.
2. Clone the repository and run `pnpm install`.
3. Follow the `AGENTS.md` and `docs/project/DELIVERY_WORKFLOW.md` for our branching and PR rules.

## Development Workflow
- Create an issue for every piece of work.
- Create a branch named `feature/<issue-number>-<desc>`.
- Make atomic commits using conventional commits.
- Push your branch and open a PR.
- Ensure all CI checks pass.

## Security
Do not commit any API keys, secrets, or sensitive configuration files.
